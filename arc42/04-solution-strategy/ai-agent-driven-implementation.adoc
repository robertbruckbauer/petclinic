== AI-agent-driven implementation, via reusable skills

The system is implemented and maintained by AI agents rather than hand-coded per change; a skill (`.agents/skills/`) operationalizes the detailed patterns in `doc/concept` into a reproducible workflow — which guide to follow, which artifacts to create or update, how to validate the result with tests — so the same kind of change is done the same way every time, by any agent.
See xref:{relrootdir}/arc42/09-architecture-decisions/0004-ai-agent-driven-implementation.adoc[ADR 0004].
