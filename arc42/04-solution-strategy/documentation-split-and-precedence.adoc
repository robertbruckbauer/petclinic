== AI-agent-driven documentation that doesn't drift

`openspec` is the normative contract, `arc42` is the bird's-eye and architecture reference, and `obsidian` is the explanatory knowledge graph; a defined precedence between them, plus the rule that an Obsidian note is a hypothesis about the code and never an independent fact, is what keeps this many documentation artifacts from silently disagreeing as the system evolves.
