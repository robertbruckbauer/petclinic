== Consistency

REST and GraphQL behave the same way for the same data.

== Traceability

Every significant backend behavior has one normative source.
A behavior spec (`openspec/specs/backend/*`) is understandable without needing technology stack details; the one deliberate exception is a `<module>-platform` capability (e.g. `backend-platform`), which is that single normative source for a technology stack instead.
