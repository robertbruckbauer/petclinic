# QueryDSL repository pattern

Every entity repository extends two of this repo's own base interfaces (`lib/backend-data/src/main/java/esy/rest/`), not raw Spring Data interfaces directly:

- `JsonJpaRepository<V>` — extends `JpaRepository<V, UUID>`, fixing every entity's id type to `UUID`.
- `QuerydslRepository<V, T>` — extends `QuerydslPredicateExecutor<V>` and `QuerydslBinderCustomizer<T>`, giving type-safe predicate-based filtering (the `Q{Entity}` classes generated by the QueryDSL annotation processor) instead of hand-written `@Query` strings for every filter combination.

This is why REST filtering (`openspec/specs/rest-conventions/spec.md`'s "request filtering" requirement) can support arbitrary case-insensitive substring/prefix filters per field without a bespoke query method for every combination — the `QuerydslBinderCustomizer` customizes how each field binds to a predicate.

Implementation baseline: `doc/concept/spring/_querydsl-repository.adoc`.
