# Agent instructions for `obsidian/`

## Role of this directory

`obsidian/` contains granular, detailed knowledge via links, MOCs and a central index.

## How a document is produced or updated

Editing files in `obsidian/` is a documentation change. It never includes editing `.java`, `.js`, `.ts`, or Gradle files — those are separate, implementation-scoped changes that a spec update may motivate but does not itself perform.
