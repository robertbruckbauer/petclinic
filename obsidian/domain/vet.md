# Vet

A **Vet** is a veterinarian employed by the clinic who conducts [Visits](visit.md). A Vet declares the skills and species they can treat, which is business information about clinic staffing/capability — not a permissions or access-control concept.

For the exact contract, see the `backend-api-vet` capability in `openspec/specs/backend-api-vet/spec.md` and `doc/service/vet-restapi.adoc` / `doc/service/vet-graphql.adoc` for the generated API reference. The UI built on it is `client-ui-vet`.
