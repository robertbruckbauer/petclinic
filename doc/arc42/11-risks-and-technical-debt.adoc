= 11. Risks and Technical Debt

Risks are kept as a table, directly in this chapter — no separate files, no numbering.
*Score* is likelihood × impact, each rated 1 (low) to 3 (high).
*Mitigation* may be empty when none is planned yet.

|===
| Risk | Score | Mitigation

| No authentication or authorization is currently enforced
| 3 (1 × 3)
| Future security plan — see ADR 0004 (`adr/0004-jwt-resource-server-and-roles.adoc`). Not yet implemented; this is an accepted, tracked risk, not an urgent defect.

| The Angular and Svelte clients still live in this repository's Gradle build (`app/client-angular`, `app/client-svelte`); neither has moved to its own standalone repository with a synced `openspec/` copy yet, and the React client (`petclinic-react-ui`) hasn't been built at all
| 2 (1 × 2)
| Target architecture and sync mechanism are decided — see ADR 0002 (`adr/0002-openspec-driven-client-generation.adoc`). Migration executes as separate follow-up work per client, gated on each standalone repo reaching feature parity. Not urgent — today's in-repo clients remain fully functional.
|===
