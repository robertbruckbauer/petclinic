= 3. Context and Scope

== Business context

Clinic staff use a browser client to manage Owners, Pets, Vets, and Visits.

== Technical context

[plantuml, target=technical-context, format=svg]
----
@startuml
!include <C4/C4_Context.puml>

LAYOUT_LEFT_RIGHT()

System(client, "Browser client", "Angular, Svelte, or a future stack")
System(server, "Backend server", "Spring Boot, Spring Data, Spring GraphQL")
SystemDb(db, "Database", "HyperSQL dev/test, PostgreSQL prod")

Rel(client, server, "REST / GraphQL", "HTTP")
Rel(server, db, "reads/writes", "JDBC")

SHOW_LEGEND()
@enduml
----

REST and GraphQL follow `openspec/specs/rest-conventions` and `openspec/specs/graphql-conventions`.
The choice between HyperSQL and PostgreSQL is explained in `openspec/specs/database-platform`.
