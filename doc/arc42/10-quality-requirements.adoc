= 10. Quality Requirements

== Quality goals

1. **Regenerability** — a browser client can be rebuilt from scratch from its specification when its technology stack changes significantly.
2. **Consistency** — REST and GraphQL behave the same way for the same data; every generated client behaves the same way for the same backend.
3. **Traceability** — every significant behavior has one normative source. A behavior spec (`openspec/specs/*`) is understandable without needing technology stack details; the one deliberate exception is a `<module>-platform` capability (e.g. `backend-platform`), which is that single normative source for a technology stack instead.
