= 10. Quality Requirements

== Regenerability

A browser client can be rebuilt from scratch from its specification when its technology stack changes significantly.
See xref:{relrootdir}/doc/arc42/adr/0002-openspec-driven-client-generation.adoc[ADR 0002].

== Consistency

REST and GraphQL behave the same way for the same data; every generated client behaves the same way for the same backend.
See xref:{relrootdir}/doc/arc42/adr/0003-rest-and-graphql-duality.adoc[ADR 0003].

== Traceability

Every significant behavior has one normative source. A behavior spec (`openspec/specs/*`) is understandable without needing technology stack details; the one deliberate exception is a `<module>-platform` capability (e.g. `backend-platform`), which is that single normative source for a technology stack instead.
See xref:{relrootdir}/doc/arc42/adr/0005-documentation-split-and-precedence-order.adoc[ADR 0005].
